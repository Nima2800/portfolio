وب سرویس API آلومینیوم دیتاست

وب‌سرویس داده‌های بازار برای دریافت اطلاعات به‌روز دلار، طلا و سکه، بورس ایران و رمزارزها از یک API واحد؛ همراه با API Key اختصاصی، پلن‌های مصرف، مستندات اتصال و پنل مدیریت کاربران و دسترسی‌ها.

مشاهده وب سرویس مشاهده طراحی‌ها

شرح پروژه

این پروژه برای یکپارچه‌سازی داده‌های مالی و بازار در قالب یک API طراحی شده است. کاربر بعد از ثبت‌نام و انتخاب پلن، کلید API دریافت می‌کند و می‌تواند داده‌های ساختاریافته موردنیاز سایت، اپلیکیشن، ربات یا داشبورد خود را از طریق endpointهای سرویس دریافت کند. رابط کاربری عمومی و پنل مدیریت نیز برای کنترل مصرف، کاربران، کلیدها و پلن‌ها طراحی شده‌اند.
